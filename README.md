# TeesZone — Apparel Manufacturing Website

Production-quality apparel manufacturing website for **TeesZone Clothing Private Limited**, based in Tiruppur, Tamil Nadu, India.

Built with **React**, **Vite**, **TypeScript**, **Tailwind CSS**, **React Router**, **Framer Motion**, and **Lucide React**.

## 🎨 Design Direction

- **Palette**: Deep Burgundy (`#800020`), Warm Cream (`#FFF7ED`), White (`#FFFFFF`), and Charcoal (`#0F172A`).
- **Typography**: Montserrat (Headings) and Inter (Body).
- **Aesthetic**: Premium industrial apparel aesthetic with organic SVG wave transitions, generous whitespace, and restrained micro-animations.

## 📄 Pages

1. **Home (`/`)**:
   - High-impact hero preserving the single-lorry factory and diverse workforce concept.
   - Six apparel categories showcase with smooth horizontal scroll and card navigation.
   - "More Than Just T-Shirts" factory preview with stats (1000+ happy clients, 100% quality, Pan India delivery).
   - "From Your Idea to Your T-Shirts" 5-step transparent manufacturing process.
   - "Why Businesses Choose TeesZone" 5 factory strengths.
   - "Custom T-Shirts for Every Sector" with 10 interactive sector spotlights.
   - Bottom branded CTA with custom hanging apparel visual.

2. **About (`/about`)**:
   - Modern factory interior hero ("Built to Represent Your Brand.", "Wear Your Identity").
   - Dual Vision & Mission cards.
   - "From Fabric to Your Brand" 4-part photo composition.
   - 5-step process and company strengths.
   - "Meet the People Behind TeesZone" 7 core leadership & team members with authentic portraits.
   - "Let's Build Your Brand Together" CTA.

3. **Products (`/products`)**:
   - 6 Core Apparel Categories: Round Neck, Polo, Oversized Streetwear, Sportswear, Corporate Wear, Custom Printed.
   - Accessible category tab filters and live search.
   - Product cards with GSM ranges, MOQs, fabric choices, branding methods, and expandable manufacturing specifications.
   - Direct bulk quote triggers.
   - Custom fabric weave and tech pack enquiry banner.

4. **Contact (`/contact`)**:
   - Client consultation hero ("Let's Create Your Custom T-Shirts Together", "We're Here to Help You!").
   - 4 Direct Contact Cards: Phone (+91 93615 43200), Email (info@teeszone.in), Location (Tiruppur, Tamil Nadu), and instant WhatsApp.
   - Accessible enquiry form with real-time validation and turnaround feedback.
   - Stylized Tiruppur interactive map preview with factory photo and Google Maps navigation.
   - Wholesale & Bulk Orders section with 5 order types.
   - "Why Contact TeesZone?" 4 direct factory advantages.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run production build
npm run build
```
